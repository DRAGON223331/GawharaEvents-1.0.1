# GawharaEvents 1.0.2

بلجن فعاليات مستقل لسيرفر GawharaSMP، مبني لـ Paper 26.3+ وJava 25+، ويستخدم Vault Economy لصرف الجوائز.

## الفعاليات الموجودة

### 1) King of the Hill (KOTH)
- يتم تحديد مركز نقطة السيطرة باستخدام `/gevents setlocation koth`.
- يقف اللاعب داخل النطاق المحدد في الكونفج.
- يجب أن يحتفظ لاعب واحد بالمنطقة لمدة `capture-seconds`.
- وجود أكثر من لاعب داخل المنطقة يجعل النقطة متنازعًا عليها ويعيد تقدم الالتقاط.
- يحصل الفائز على مكافأة Vault.

### 2) Treasure Hunt
- يختار البلجن موقعًا آمنًا عشوائيًا حول مركز البحث.
- يضع صندوقًا مؤقتًا في المكان، ويعلن تلميحات إحداثيات تقريبية تتدرج في الدقة.
- أول لاعب يضغط بالزر الأيمن على الصندوق يفوز بالمكافأة.
- يتم استرجاع البلوك الأصلي بعد المطالبة أو انتهاء الوقت أو إيقاف البلجن.

### 3) Meteor Drop
- يختار البلجن موقعًا آمنًا عشوائيًا حول مركز النيزك.
- يُسقط كتلة ماجما مرئية من السماء بسرعة إلى نقطة الحدث، دون إلحاق ضرر باللاعبين ودون ترك بلوك في العالم.
- ينشئ صندوق مكافأة مؤقتًا ويشغّل مؤثرات نار وانفجار وصوت عند الاصطدام.
- يتم إعلان العالم والإحداثيات للاعبين.
- أول لاعب يفتح الصندوق بالمؤشر الأيمن يفوز بالمكافأة.

## المتطلبات

- Paper 26.3 أو أحدث.
- Java 25 أو أحدث.
- Vault.
- بلجن اقتصاد يوفر Vault Economy مثل EssentialsX Economy.

## التثبيت

1. ضع `GawharaEvents-1.0.2.jar` داخل `plugins`.
2. تأكد من وجود Vault وبلجن الاقتصاد.
3. أعد تشغيل السيرفر.
4. عدّل `plugins/GawharaEvents/config.yml`.

## ضبط المواقع داخل اللعبة

قف في المكان الذي تريده ثم نفّذ بصلاحية `gawharaevents.admin`. العوالم الافتراضية فارغة عمدًا حتى لا تبدأ فعالية في إحداثيات غير مقصودة:

```text
/gevents setlocation koth
/gevents setlocation treasure
/gevents setlocation meteor
```

- KOTH: الموقع الذي تقف فيه هو مركز نقطة السيطرة.
- Treasure/Meteor: الموقع الذي تقف فيه هو مركز البحث، ويختار البلجن موقعًا آمنًا عشوائيًا حوله.
- أبقِ نطاق البحث داخل ساحة فعاليات عامة؛ البلجن يضع صندوقًا مؤقتًا مباشرة عبر Bukkit API، لذلك لا تعتمد على أن بلجنات الحماية ستمنع تغييره تلقائيًا في المناطق المحمية.

## أوامر اللاعبين

```text
/gevents
/gevents status
/events
```

## أوامر الإدارة

```text
/gevents start koth
/gevents start treasure
/gevents start meteor
/gevents stop
/gevents setlocation <koth|treasure|meteor>
/gevents reload
```

## الصلاحيات

- `gawharaevents.use`: عرض معلومات الفعاليات (افتراضيًا للجميع).
- `gawharaevents.admin`: تشغيل وإيقاف الفعاليات وضبط مواقعها وإعادة تحميل الكونفج (افتراضيًا OP).

## الجدولة التلقائية

من `config.yml`:

```yaml
auto-events:
  enabled: true
  first-delay-seconds: 900
  interval-seconds: 10800
  types:
    - koth
    - treasure
    - meteor
```

الجدولة معطلة افتراضيًا إلى أن تضبط مواقع الفعاليات الثلاثة.

## المكافآت

```yaml
rewards:
  koth: 750.0
  treasure: 1000.0
  meteor: 1500.0
```

كل المكافآت تُصرف عبر Vault Economy. إذا رفض مزود الاقتصاد عملية الإيداع، يسجل البلجن الخطأ ولا يعلن نجاح الدفع.

## البناء من السورس

يتطلب Maven وJava 25 واتصال إنترنت لتحميل Paper API وVaultAPI:

```bash
mvn clean package
```

الملف الناتج:

```text
target/GawharaEvents-1.0.2.jar
```

يوجد GitHub Actions workflow لبناء الـ JAR تلقائيًا عند رفع المشروع.

## ملاحظات تشغيلية

- Treasure وMeteor يضعان صندوقًا مؤقتًا فوق سطح آمن. يحفظ البلجن بيانات البلوك السابق في `state.yml` حتى يحاول استرجاعه بعد إعادة التشغيل غير المتوقع.
- لا تضع مركز البحث داخل منطقة محمية تمنع تعديل البلوكات؛ قد تمنع بلجنات الحماية وضع الصندوق. جرّب الفعالية في منطقة مسموح فيها تعديل البلوكات.
- KOTH يقيس وجود اللاعبين داخل نطاق دائري حول المركز. يجب أن تكون نقطة المركز في نفس مستوى المنطقة التي سيقف فيها اللاعبون.
- نسّق الفعاليات مع بلجنات الحماية والـ WorldGuard، واسمح للبلجن بوضع وإزالة صندوق الفعالية.
